# Структура папки data/

Эта папка содержит данные для разных серверов Minecraft. Каждый сервер должен иметь свою подпапку.

## Структура:

```
data/
├── vanilla/          # Данные ванильного сервера
├── terrafirmagreg/   # Данные сервера с модпаком TerraFirmaGreg
├── modpack1/         # Данные другого модпака
└── ...
```

## Использование:

Для выбора папки данных сервера используйте переменную `SERVER_DATA_DIR` в файле `.env`:

```env
# Для ванильного сервера
SERVER_DATA_DIR=vanilla

# Для модпака TerraFirmaGreg
SERVER_DATA_DIR=terrafirmagreg
```

## Важно:

- Каждый сервер должен иметь свою папку
- Не используйте одну и ту же папку для разных серверов
- При переключении между серверами меняйте `SERVER_DATA_DIR` в `.env`
- После изменения `SERVER_DATA_DIR` перезапустите контейнеры: `docker compose down && docker compose up -d`
